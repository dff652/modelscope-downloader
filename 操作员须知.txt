============================================================
 ModelScope 模型下载工具 —— 操作员一页纸
============================================================

这是什么：双击就能从 ModelScope 下载 AI 模型。普通模型可打包成一个文件；
超大模型可按容量分成多批，拿去传给没有网络的部署机器。分批不需要手动导出，
也不需要、不能把权重文件拼接成新文件。

------------------------------------------------------------
 第一次用，可能会遇到的一个提示
------------------------------------------------------------
Windows 可能弹蓝色窗口「已保护你的电脑 / SmartScreen」。
这是因为程序没有花钱买签名，不是病毒。
点【更多信息】→【仍要运行】即可。

------------------------------------------------------------
 操作步骤
------------------------------------------------------------
1) 双击  ModelScopeDownloader.exe  ，会弹出一个窗口。

2) 「模型 id」：下拉选常用的，或直接粘贴别人给你的 id
   （例如  Qwen/Qwen3-0.6B ）。注意区分大小写，照抄。

3) 「保存到文件夹」：点【浏览…】选一个空间大的磁盘目录。
   - 普通小模型几百 MB 即可。
   - 大模型可能 300G，请选 ≥350G 空闲的盘；
     如果还要打包，再多留一份同样大小的空间。

4)（可选）勾上「跳过图片/视频等演示文件」，下得更快更省空间。
   推理部署用不到这些演示文件，勾了更好。

5) 点【下载 / Download】，然后等。
   - 窗口里有进度条、百分比、网速和预计剩余时间。
     （刚点完的前一小会儿显示「查询模型清单」没进度，是正常的）
   - 想暂停？点【停止】就行。之后再点【下载】会从断点接着下。
   - 中途断网或不小心关了？也没关系：重新打开、填同一个模型、
     再点一次下载，会从断点接着下，不会从头来。
   - 如果日志里出现「磁盘剩 XX 不够」的红字提示，
     点【停止】，换个更大的盘再来。

6) 下完会弹窗问「现在打包成 .tar 吗？」→ 点【是】。
   工具会自动生成两个文件：
        <模型名>.tar
        <模型名>.tar.sha256
   （就在你第 3 步选的那个文件夹里）

7) 把这【两个文件一起】拷贝到 U 盘 / 移动硬盘，交给部署的同事。
   两个都要，缺一不可（.sha256 是用来校验没传坏的）。

------------------------------------------------------------
 超大模型（例如完整模型放不进下载机）
------------------------------------------------------------
前提：离线服务器最终磁盘能放下完整模型；分批不能减少最终模型大小。

1) 勾选【离线分批下载】。
2) 「每批上限」填移动盘和本地都能容纳的大小，例如 100 GB；建议再留
   10%–20% 空间，不要把数值填到磁盘剩余空间。 「下载第」先填 1。
   点下载后界面会自动显示总共多少批。工具支持设置每批大小，但不支持
   直接指定总批数；总批数由模型的完整文件清单自动计算。
   第一次会锁定批次计划；后续不能中途更改模型、过滤选项、保存目录或每批大小。
3) 完成后搬走整个 batch-001 文件夹。不要改文件名，不要拼接
   model-00001-of-xxxxx.safetensors 等权重文件。
4) batch-001 内有：
      _OFFLINE-SHA256SUMS.batch-001   本批校验码
      _OFFLINE-VERIFY.py              Windows/Linux 都能运行的校验工具
      _OFFLINE-SERVER-INSTRUCTIONS.txt 服务器复制、校验和总验收命令
5) 部署同事使用 `_OFFLINE-SERVER-INSTRUCTIONS.txt`：Linux 部分用
   `rsync` 复制本批文件，Windows 部分用 `robocopy` 复制本批文件；
   再用说明中的 `python3`/`python` 校验命令。服务器不需要访问 ModelScope，
   校验脚本只用 Python 标准库。把每批模型文件合入同一个最终模型目录，
   并先完成本批校验。只有服务器校验通过，才能删除下载机/移动盘上的本批。
6) 界面会自动切到下一批。继续下载、搬运、校验，直到全部批次完成。
7) 所有批次上传后，执行说明文件末尾的「全部批次总校验」命令；
   Linux 和 Windows 都会先逐一检查 batch-001 到最后一批的校验清单，
   再检查总数量，随后校验全部文件，避免旧清单或错编号蒙混过关。
   显示 checked=文件数、failed=0 才算完成。

注意：离线分批模式不需要也不能打 tar；每个权重分片本来就是完整文件。

------------------------------------------------------------
 遇到问题怎么办
------------------------------------------------------------
- 卡住不动 / 报错看不懂：截图整个窗口，连同你填的模型 id，
  发给开发同事。
- 提示「model not found / 404」：多半是模型 id 抄错了，
  重新核对大小写和有没有多余空格。
- 提示盘满：普通模式换更大的盘；离线分批模式减小「每批上限」。
  如果某一个权重文件本身就比移动盘大，分批也无能为力，必须换更大介质。

============================================================
 记住三件事：① 不拼接权重  ② 每批先校验再删除  ③ 全部到齐再总验收
